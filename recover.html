שחזור מהזיכרון של הטלפון

  1. לפני שנכנסתם לכאן: סגרו לגמרי את אפליקציית כוח האדם (גם מהאפליקציות האחרונות).
  2. אחרי שהדף הזה נטען — העבירו את הטלפון למצב טיסה.
  3. לחצו "קרא מהזיכרון".
טוען…
    מה עכשיו?
    1. הגיבוי נשמר גם בטלפון הזה וגם בקובץ.
    2. אפשר לצאת ממצב טיסה.
    3. שלחו את הקובץ למנהל. המנהל פותח את האפליקציה ← ⚙︎ הגדרות ← "שחזור נתונים שנמחקו" ← "שחזור מקובץ גיבוי".
    4. או: פתחו כאן את האפליקציה ← ⚙︎ הגדרות ← "שחזור נתונים שנמחקו" ← בוחרים את הגיבוי "מהזיכרון של הטלפון".
